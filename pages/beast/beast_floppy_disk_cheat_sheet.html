Floppy Disk Cheat Sheet

Beast From Beyond Main Quest

During the Main Quest, you'll need to find 4 floppy disks, each with a different symbol on them. Based on these symbols, you need to match all four to one specific group shown in the graphic

Below is a graphic of all the groups and which symbols make up each group. Make sure, when placing the floppy disks into Neil, you also take into account the order the symbols appear in the group (read top to bottom).

I also plan on adding a tool that allows you to just select which floppy disk symbols you got in game and it will give out the solution to put into Neil.
